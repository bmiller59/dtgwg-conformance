# Maintainers

> **Status: draft proposal.** This is a draft proposal for discussion and review by the DTGWG (Trust over IP Decentralized Trust Graph Working Group). It is not an adopted or endorsed standard or test suite.

Maintainers are listed by role. Names and contact details are not kept in this file; the host's repository settings show who holds each role.

| Role | Responsibility |
|---|---|
| Project owner | Decides the scope of the suite and which decisions are recorded in [docs/decisions/README.md](docs/decisions/README.md); reviews changes to platforms before they are proposed upstream; receives private security and conduct reports (see [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)). |
| Maintainers | Review and merge pull requests, triage issues, keep the generated pages current (`npm run regen`, `npm run check:docs`). Anyone with the right to merge is a maintainer. |

## How the roles change

The project owner role is expected to move to a working-group-appointed group if the suite is donated. Until then, a new maintainer is added by the project owner after a sustained record of reviewed contributions. Anyone can ask to be considered by opening a discussion on the repository.

## Reaching the maintainers

Use the repository's issues for problems with a vector, GitHub Discussions on the repository for questions and ideas (see [CONTRIBUTING.md](CONTRIBUTING.md#where-to-discuss)), and private reporting for security and conduct matters.
