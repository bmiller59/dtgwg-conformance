# Credits

> **Status: draft proposal.** This is a draft proposal for discussion and review by the DTGWG (Trust over IP Decentralized Trust Graph Working Group). It is not an adopted or endorsed standard or test suite.

This conformance suite exists because of other people's work, and this page says whose.

## The layer model

The layer model in [01-layer-model.md](01-layer-model.md) and the way the suite is organised by layer were proposed by Brendan A. Miller (the layer model used in the orientation diagram). They build on the standard Trust over IP model (its layer numbering), with added detail.

## M. Kolpondinos: the interoperability / interworking / meta-layer-roles deck

The vocabulary in [12-interoperability-interworking-meta-layer.md](12-interoperability-interworking-meta-layer.md) (the three questions, their definitions and the comparison between them) comes from a working-draft slide deck, used with credit:

- M. Kolpondinos (Kosma Connect, Trust Stackers, DTG), *Interoperability, Interworking, Meta-layer Roles — or something else? Making sure we are talking about the same thing*, Interopathon, CA, 9 Nov 2026. Working draft for discussion (9 slides). The byline is quoted as printed on the deck.

The deck is a working draft for discussion. It is not copied into this repository; docs/12 summarises it. Where docs/12 applies the vocabulary to this suite, that is this repository's reading, not the deck's. This page credits the deck and nothing else.

## Other sources the suite uses

- The Trust Tasks framework and task specifications, and the task-force conformance fixtures reused unchanged under `vectors/imported/` (see `vectors/imported/PROVENANCE.json` and the licence note in `NOTICE`).
- The implementations the suite is measured against: VTI (verifiable-trust-infrastructure), keyring-wallet and truststackers. Their maintainers' work is what the suite exists to help; the results are offered to them in that spirit.
- The `@openvtc/trust-tasks` runtime (Apache-2.0), on which the reference adapter is built.
