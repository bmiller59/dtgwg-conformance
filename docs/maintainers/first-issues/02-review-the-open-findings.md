# First issue 2: review the open findings

> **Status: draft proposal.** This is a draft proposal for discussion and review by the DTGWG (Trust over IP Decentralized Trust Graph Working Group). It is not an adopted or endorsed standard or test suite.

This page is the text of one "we need reviewers" issue, kept here so the maintainers can open it as written once the repository is public. Nothing has been posted or sent. Every task specification this suite reads is a draft, and so is the suite.

## Title

Review request: questions the specifications leave open

## Body

While writing checks from the draft specifications we found places where the text does not settle what should happen, or where two documents seem to say different things. The suite does not guess in those places: it records a question, with the quoted text on both sides, and the check stays advisory (it does not decide a pass or fail) until someone who owns the text answers.

The current list of these questions, and of the other open items, is on the [open gaps page](../../community/open-gaps.md), in the section "Questions for the task force (not to be asserted)". Every specification involved is a draft, so some of these may already be answered by a newer version; if so, that is the quickest answer of all.

## What we ask

1. Open the [open gaps page](../../community/open-gaps.md) and go to the questions section.
2. For each question you can answer, tell us which of these it is:
   - the text already decides it (quote the sentence);
   - the text should decide it and does not (a change to the specification is wanted);
   - either behaviour is allowed, and the check should accept both.
3. Tell us if a question is missing, or is badly worded.

You do not need to answer all of them. Any single answer lets us turn one advisory check into a firm one, or remove it.

## How to reply

Comment on this issue with the question's number or short name and your answer, or start a discussion thread if the answer needs a longer talk. We will update the suite and record your answer with the date. Nothing is changed in any platform on the strength of these questions; they only decide how the suite reads the text.
